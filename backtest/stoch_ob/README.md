# Stochastic + Order Block: Backtest XAUUSD M30

สเปกเต็มอยู่ใน [`DESIGN.md`](DESIGN.md) · โค้ด `stoch_ob.py` · tests `test_stoch_ob.py` (24 tests) · runner `run_backtest.py`

## กติกา (ค่าเริ่มต้น)
- **SELL**: %K อยู่ในโซน 80–100 แล้วกลับทิศลง → เข้าที่ราคาปิด · **BUY**: %K อยู่ในโซน 0–20 แล้วกลับทิศขึ้น
- **SL**: เหนือ high สูงสุด (ใต้ low ต่ำสุด) ของ 10 แท่งล่าสุด + spread
- **TP**: OB ที่ใกล้สุดในทิศทางนั้น หรือ %K ถึงโซนตรงข้าม แล้วแต่อะไรถึงก่อน (ข้ามเทรดถ้า OB ใกล้กว่า 1R)
- Stochastic (14,3,3) แบบ MT5 · 1 ไม้ต่อการเข้าโซน 1 รอบ · ถือทีละไม้ · spread 0.30 USD (2012–22), 0.50 USD (2026)

## การตรวจสอบโค้ดก่อน backtest
- Agent ตรวจโค้ดแยก 2 รอบ: รอบแรก **NOT READY** (พบ 11 ข้อ) → แก้ → รอบสอง **READY**
- เขียน reference implementation อิสระจาก spec แล้วเทียบ: ตรงกัน 100% (9,449 เทรด, 18 configs)
- ไม่พบ look-ahead · โมเดล bid/ask สมมาตรระหว่าง BUY/SELL · ทดสอบใส่บั๊กจงใจ 43 แบบเพื่อวัดความแรงของ tests

## ทดสอบเพิ่ม: ตัวกรองเทรนด์ H4 (`run_htf.py`, spec ข้อ 9)
SELL เฉพาะเมื่อ H4 เป็นขาลง · BUY เฉพาะเมื่อ H4 เป็นขาขึ้น · เทรนด์ H4 แบบ **โครงสร้างตลาด** (ปิดทะลุ swing) และแบบ **EMA50**
· ผ่าน review รอบที่ 3 (READY, ไม่พบ look-ahead) · ข้อมูลปี 2026 แปลงเป็นเวลา server ให้แท่ง H4 ตรงกับ MT5

- **ตัวกรองเทรนด์ H4 ไม่ช่วยกลยุทธ์นี้:** ลดจำนวนไม้ลงครึ่งหนึ่ง แต่ PF แทบไม่เปลี่ยน (IS 0.77–0.94, OOS 2018–22 0.64–0.74)
- **ถ้าไม่หัก spread:** 2012–17 PF 1.14 · 2018–22 PF 0.84–0.92 เหมือนกับไม่กรอง → ตัวกรองไม่ได้เพิ่ม edge
- **โดน SL ยังคงที่ 62–79%** แม้จะเทรดตามทิศเทรนด์ใหญ่
- 2026 มีบางแบบ PF > 1 แต่มีแค่ 72–84 ไม้ (t < 1.5) และแบบเดียวกันขาดทุนชัดเจนในช่วง 2018–22 จึงเป็นความบังเอิญ
